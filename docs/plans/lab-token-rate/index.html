Token rate in the Lab

Three ways to show the new tokens field. The main number is output tokens per minute. It is output tokens divided by the run time.

Most of the input is cache reads, often 95% or more. Total tokens per minute would mostly measure the cache, so it is not a main number.

All mocks use one benchmark, Void Cruiser 3D. The eight token runs are sample data at a realistic scale. The other runs stand in for older runs and for agents that do not report tokens.

Option A

A token column in the run list

Each run row on the benchmark page gets a column for output tok/min. A short line under it gives output and cache share. Hover or focus the column to see the full count.

Option B

A token panel on the run page

The run detail page gets a panel under the score cards. It shows output tok/min as the main number, then the counts and a bar that splits input into cached and fresh. Runs with no data get one short line.

A speed against score chart
